# 原神体检助手（genshin-checker-release）

基于 **uid 一键查询** 的原神账号体检工具：输入 uid 即可查询账号基本信息，并提供每角色的**多维度诊断**与**优化建议**。纯前端单页，手机与桌面均可使用。

## ✨ 功能

- **一键查询**：输入 uid（支持历史记录）→ 展示账号总览（冒险等级 / 区服 / 角色数量 / 90 级角色数）。
- **角色列表**：总览页横向滑动查看全部角色，点击进入单个角色详情。
- **角色详情**：等级 / 武器 / 天赋 / 职业标签、面板属性、关键属性条形图、5 件圣遗物明细。
- **规则诊断**：根据角色数据自动预判短板（暴击率太低、爆伤不足、武器等级落后、圣遗物等级偏低、充能不够等）。
- **AI 优化建议**：从【圣遗物 / 武器 / 天赋 / 面板 / 配队】五个方面给出建议，默认内置，也可在设置中自行配置自定义服务。

## 🚀 使用

1. 打开页面，输入 uid → 点击「一键查询」。
2. 点进任意角色 → 查看属性和圣遗物 → 生成优化建议。

> 数据与配置仅在本机浏览器处理，注重使用体验与隐私。
